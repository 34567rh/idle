Sign in to the GitHub account that can access this repository. If a link opens a file page, use its **Download raw file** button.

To leave the cloud: download the ZIP, extract it on your computer, and open `The_Idle_Mines_Recovery/build/The_Idle_Mines_Recovered.rbxl` in Roblox Studio. The ZIP includes source code, the preserved original place, dependencies, checks, and documentation.

The rebuilt core passes 20 offline behavioral tests, formatting, Roblox type analysis, and place build/reopen checks. Roblox Studio engine playtesting is still pending. The original game's gear, potions, shops, and minigames are not rebuilt. See the project README for details and the Studio test checklist.
